# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub instead: open the repository's **Security** tab
and choose **Report a vulnerability**. Only the maintainers can see the report.

Include what you found, how to reproduce it, and which version or commit you used.
We will reply as soon as we can and keep you updated while we work on a fix.

## Supported versions

Fixes go into the latest release on `main`.
